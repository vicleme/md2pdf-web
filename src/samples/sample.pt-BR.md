# Bem-vindo ao MD2PDF

Escreva ou cole **Markdown** à esquerda, veja o resultado à direita e depois baixe como *PDF*. Tudo acontece no seu navegador, então seus arquivos nunca saem do seu computador.

## O que é suportado

- Títulos, parágrafos, **negrito**, *itálico* e ~~tachado~~
- Listas ordenadas e não ordenadas
- Links, imagens e citações
- Tabelas e listas de tarefas (GitHub Flavored Markdown)
- Blocos de código e `código em linha`

### Uma pequena lista de tarefas

- [x] Abrir um arquivo `.md`
- [x] Ajustar as opções do PDF
- [ ] Baixar seu PDF

### Uma tabela

| Formato  | Texto selecionável | Tamanho do arquivo |
| -------- | :----------------: | -----------------: |
| Baixar   | Não (imagem)       | Maior              |
| Imprimir | Sim                | Menor              |

> Dica: o botão "Imprimir / Salvar como PDF" mantém o texto selecionável e gera arquivos menores.

### Um pouco de código

```js
function saudar(nome) {
  return `Olá, ${nome}!`;
}
```

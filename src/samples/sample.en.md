# Welcome to MD2PDF

Write or paste **Markdown** on the left, see the result on the right, then download it as a *PDF*. Everything happens in your browser, so your files never leave your computer.

## What is supported

- Headings, paragraphs, **bold**, *italic* and ~~strikethrough~~
- Ordered and unordered lists
- Links, images and blockquotes
- Tables and task lists (GitHub Flavored Markdown)
- Code blocks and `inline code`

### A small checklist

- [x] Open a `.md` file
- [x] Tweak the PDF options
- [ ] Download your PDF

### A table

| Format   | Selectable text | File size |
| -------- | :-------------: | --------: |
| Download | No (image)      | Larger    |
| Print    | Yes             | Smaller   |

> Tip: the "Print / Save as PDF" button keeps the text selectable and produces smaller files.
